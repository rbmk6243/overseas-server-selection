## 先定三件事，再去比商家

第一件是用户在哪。做外贸独立站、面向北美客户，把机器放在洛杉矶或美国东部（阿什本、新泽西、纽约州布法罗、亚特兰大）都合理；客户集中在欧洲，阿姆斯特丹比美西更近。第二件是国内访问要不要快。第三件是你能接受什么计费周期，以及第二年按什么价续。

按场景分，规则大致是这样：

- **外贸站、面向欧美用户**：优先美国东部或西部机房，延迟对美国本地用户是十几毫秒量级，国内打开慢一点不影响成交。
- **中文个人博客、又不想备案**：香港或日本节点更合适。这类需求 RackNerd 帮不上，它没有亚洲机房，从国内连过去 120ms 起步。
- **跑东亚业务、日韩流媒体、面向东亚的游戏服**：直接看有东京、首尔、新加坡节点的商家，别在美国机房里绕。
- **要大带宽、大流量、多 IP**：美国机房在这一项上性价比最高，1Gbps 端口和每月几 TB 到几十 TB 的流量是常规配置。

## 便宜是有原因的：三个必须接受的设定

**只有一个 IPv4。** 全系套餐标配 1 个 IPv4 地址，需要站群、多 IP 的业务不适合这一档。这是低价 VPS 的通行做法，不是它一家的问题。

**无管理（unmanaged）。** 系统安全、环境配置、数据备份都是你自己的事。官方 24/7 支持管的是平台层面：机器起不来、面板进不去、网络异常。你说“帮我装个宝塔”“帮我调一下 MySQL”，不在服务范围里。会 Linux 的人这叫省心，不会的人这叫花钱买麻烦。

**端口速率不等于保证带宽。** 1Gbps 说的是端口速率，套餐里同时给了流量上限（1G 档 3TB，8G 档 20TB）。跑视频分发、做下载站这类持续打满的业务，先算清楚流量够不够，别只看端口数字。

另外提一句，第三方用户评价里有人提到 PTR 记录提交后十分钟内就改好了，也有人提到它不封 25 端口。这两条是用户自述，不是官方承诺，但对你如果有发信需求，值得下单前开工单确认一次。

## 常见问题

**国外服务器需要备案吗？**
海外节点不需要 ICP 备案，开通即用。但机房所在地的法律和商家的 AUP（可接受使用政策）仍然约束你放什么内容，这一点和备案是两回事。

**能直接用支付宝付款吗？**
RackNerd 支持支付宝、银联、PayPal、信用卡和加密货币，国内用户不需要找人代付。

**年付一定比月付划算吗？**
不一定，要看商家的定价结构。RackNerd 的 specials 以年付为主，年付锁定了当年的价格；有些商家年付确实比月付便宜三成左右（这是部分商家的个例，不能套到所有品牌上）。年付真正的风险在于你用了两个月就不用了，退款条款又没看清。下单前先确认退款和取消政策，这一项 RackNerd 的公开页面上没有明确写出，需要你自己在结算页或开工单问清楚。

**晚高峰卡怎么办？**
先用 Looking Glass 在你自己的网络环境里测一遍再买，别等买完才发现绕路。已经在用的，跑一次 traceroute 把结果发给支持，问清楚是不是线路调整。

**1GB 内存够不够？**
跑一个轻量博客够，跑 WordPress + 宝塔 + MySQL 就紧张。加 14 美元从 1GB 升到 2GB，比后期迁移数据省事。
